# 过程文件说明 · 校验渲染/

人工核对用的渲染图。由 `tests/test_regression.py` 在每次跑测试时**自动重新生成**，
用于确认「配置是否真的按预期生效」「边界用例是否画得对」——这是绘图类项目最容易出错的地方。

## 子目录

### `配置核对/`
对同一城市（北京 237）逐一应用**每一套内置配置**，用于横向比对配置效果。

| 文件 | 核对要点 |
|---|---|
| `北京_default.png` | 默认配置：是否与官方页面观感一致（最低/最高气温平滑线 + 降水柱 + 双轴） |
| `北京_full.png` | 5 个元素同图、第三轴（降水日数）刻度是否正确、极值标注是否可读 |
| `北京_temp_only.png` | 最高/最低之间的区间带（fill_between）是否填充正确 |
| `北京_rain_only.png` | 单轴降水柱 + 降水日数折线、缩放说明是否出现在图例标题 |
| `北京_presentation.png` | 大画布大字号、数据标签是否溢出 |
| `北京_paper.png` | 白底、无图例边框、左对齐标题、数据来源署名位置 |
| `北京_compact.png` | 紧凑尺寸下月份标签是否拥挤 |
| `北京_minimal.png` | 标题/图例/网格/轴标题是否确实消失 |
| `北京_seasonal.png` | 季节底色带与月份是否对齐（冬=12/1/2 跨年） |
| `北京_alt_bands.png` | 隔月底色是否落在偶数月 |
| `北京_fahrenheit.png` | 单位换算后数值与轴标题是否为 °F / 英寸 |
| `北京_yellow_black.png` | 高对比配色与第三轴并存 |
| `北京_annual_table.png` | 表格型配置下图形是否仍正常 |

### `边界用例/`
针对实测发现的**数据异常**做渲染核对。

| 文件 | 核对要点 |
|---|---|
| `香港_默认.png` | 降水为小数（如 33.2 mm）时刻度与柱高是否正常 |
| `希洪_空单位.png` | `raintype` / `rainunit` 均为空串时，图例名与轴标题是否正常兜底 |
| `新西伯利亚_含0降水.png` | 存在 0 值月份的柱状图是否有误导性缺口 |
| `塔里_降水全缺自动降级.png` | 降水数据全缺时是否**自动降级为纯气温图**而不报错 |
| `塔里_full配置_降水全缺.png` | 全缺元素 + full 配置（三轴）下是否仍能正常出图 |
| `卢森格林_气温全缺.png` | 气温全缺的纯降水城市是否能正常出图 |
| `香港_全元素三轴.png` | 三轴同时存在时标签是否重叠 |

### `多城市对比/`
| 文件 | 核对要点 |
|---|---|
| `三城对比_气温.png` | 配色/线型/标记轮换是否可区分，图例数值范围是否正确 |
| `三城对比_降水.png` | 降水元素对比（柱状）与排序 |
| `三城对比_柱状.png` | 多城市柱状并置时的分组与间距 |

## 说明

- 这些图**不是交付物**，仅用于开发期人工核对；交付示例见项目根 `output/`。
- 每张图都由断言守护（文件存在且体积 > 5 KB），渲染失败会导致回归测试失败。
