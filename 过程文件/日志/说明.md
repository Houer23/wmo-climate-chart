# 过程文件说明 · 日志/

各次执行日志，用于追溯问题与留证。均为文本文件，无程序依赖，可随时删除。

| 文件 | 内容 |
|---|---|
| `环境安装日志.log` | 隔离虚拟环境的依赖安装记录（matplotlib / openpyxl / numpy 版本） |
| `_test_run1.txt` `_test_run2.txt` `_test_run3.txt` | 三次回归测试输出（前两次用于定位缺陷：`annual` 精度键报错、转置月份重复；第三次全绿） |
| `_test_smoke.txt` | 首次冒烟测试（北京 237）输出 |
| `_test_files.txt` `_demo_files.txt` | 产出文件清单 |
| `_test_fixtures.txt` `_test_fixtures2.txt` | 测试夹具抓取输出（第一次 6 个样本，第二次补充 3 个缺失值样本） |
| `_cli_sweep.txt` | **CLI 18 个子命令的完整验收报告**（含 stdout/stderr 与退出码） |
| `_cli_sweep_console.txt` | CLI 验收的控制台摘要 |
| `_demo_gen.txt` | 交付示例生成时的命令与输出 |
| `_scan_missing.txt` | 抽样城市缺失值分布扫描结果（定位到塔里/圣保罗/卢森格林等边界样本） |

> 文件名以 `_` 开头者为工具运行期的原始日志，保留原名以便与源码中的记录对应。
