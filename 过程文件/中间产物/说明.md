# 过程文件说明 · 中间产物/

半成品数据与运行期缓存。**可以安全删除**（程序会自动重建），删除后仅会影响速度与离线测试能力。

| 子目录 | 内容 | 删除影响 |
|---|---|---|
| `cache/` | HTTP 响应缓存（含城市页面、城市数据文件、城市索引归一化结果） | 下次运行会重新联网请求；离线场景需联网 |
| `cache/city_index.json` | 归一化后的城市索引（3629 城，便于名称反查） | 下次按名称查城市时会重新拉取 1.1 MB 索引 |
| `cli_sweep/` | CLI 全子命令验收时的输出产物（批量/对比/英制/无图/无表等） | 无影响，可随时重跑 `过程文件/脚本/cli_sweep.py` 生成 |
| `test_out/` | 回归测试中表格用例的中间输出（含年列、转置、英制、缺失值等变体） | 无影响，每次跑测试会重建 |

## 说明

- 缓存键是 URL 的 SHA1 前 20 位，`*.meta.json` 记录状态码与写入时间；有效期由配置 `fetch.cache.ttl` 控制（默认 1 天）。
- `save_raw` 配置为 `true` 时，原始响应会另存到 `中间产物/raw/`，便于排查站点结构变化。
- 缓存与原始响应的目录位置均由配置控制（`fetch.cache.dir` / `fetch.raw_dir`），相对路径基于项目根解析。
