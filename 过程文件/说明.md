# 过程文件说明

本目录存放**非交付**的过程产物，按作用分类。交付物在项目根的 `output/` 目录。

| 子目录 | 作用 | 说明文件 |
|---|---|---|
| `脚本/` | 可复用的处理与验收脚本（纯代码） | [脚本/说明.md](脚本/说明.md) |
| `侦察/` | 开发前的接口侦察产物与实测证据 | [侦察/说明.md](侦察/说明.md) |
| `校验渲染/` | 人工核对的渲染图（各配置、各边界用例） | [校验渲染/说明.md](校验渲染/说明.md) |
| `中间产物/` | 半成品数据：请求缓存、原始响应、测试中间输出、CLI 验收输出 | [中间产物/说明.md](中间产物/说明.md) |
| `日志/` | 各次执行日志（安装、测试、CLI 验收、示例生成） | [日志/说明.md](日志/说明.md) |

## 可复用的核心能力（如何调用）

| 能力 | 调用方式 |
|---|---|
| 抓取并更新测试夹具 | `python 过程文件/脚本/fetch_fixtures.py` |
| CLI 全子命令端到端验收 | `python 过程文件/脚本/cli_sweep.py` |
| 扫描样本中的缺失值分布 | `python 过程文件/脚本/scan_missing_values.py` |
| 接口侦察（字段完整性抽样） | `python 过程文件/侦察/recon_probe.py <Country_zh.xml路径> [抽样数]` |
| 边界行为侦察（404 / TLS 断连） | `python 过程文件/侦察/recon_probe2.py <Country_zh.xml路径>` |
| 回归测试 | `python tests/test_regression.py [--network]` |

> 脚本均位于 `过程文件/脚本/` 与 `过程文件/侦察/`，内部已自行定位项目根目录，可在任意工作目录下调用。
