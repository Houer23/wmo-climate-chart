# 过程文件说明

本目录只存放**开发过程留证**（非交付物、非运行产物）。

其余产物已按语义归档到项目根：

| 产物 | 位置 |
|---|---|
| 交付物（表格与图） | `output/` |
| 运行缓存（HTTP / 城市索引 / 原始响应） | `cache/` |
| 运行日志与验收报告 | `logs/` |
| 测试产物（渲染核对图 / 表格中间输出） | `tests/_output/` |
| 可复用脚本 | `scripts/` |

## 目录内容

| 子目录 | 作用 | 说明文件 |
|---|---|---|
| `侦察/` | 开发前的接口侦察脚本与实测证据（`开发计划.md` 各项结论的来源） | [侦察/说明.md](侦察/说明.md) |

## 可复用的核心能力（如何调用）

| 能力 | 调用方式 |
|---|---|
| 抓取并更新测试夹具 | `python scripts/fetch_fixtures.py` |
| CLI 全子命令端到端验收 | `python scripts/cli_sweep.py` |
| 扫描样本中的缺失值分布 | `python scripts/scan_missing_values.py` |
| 接口侦察（字段完整性抽样） | `python 过程文件/侦察/recon_probe.py <Country_zh.xml路径> [抽样数]` |
| 边界行为侦察（404 / TLS 断连） | `python 过程文件/侦察/recon_probe2.py <Country_zh.xml路径>` |
| 回归测试 | `python tests/test_regression.py [--network]` |

> 可复用脚本位于项目根 `scripts/`，侦察脚本位于 `过程文件/侦察/`，内部均自行定位项目根目录，可在任意工作目录下调用。
