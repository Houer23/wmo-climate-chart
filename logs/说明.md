# 运行日志 logs/

项目运行与脚本执行产生的日志、验收报告，用于追溯问题与留证。均为文本文件，无程序依赖。

| 文件 | 内容 |
|---|---|
| `环境安装日志.log` | 隔离虚拟环境的依赖安装记录（matplotlib / openpyxl / numpy 版本） |
| `_test_run_final.txt` | **回归测试最终输出（全绿）**；历史的三次定位日志 `_test_run1~3.txt` 已清理 |
| `_test_smoke.txt` | 首次冒烟测试（北京 237）输出 |
| `_test_fixtures.txt` `_test_fixtures2.txt` | 测试夹具抓取输出（第一次 6 个样本，第二次补充 3 个缺失值样本） |
| `_scan_fixtures.txt` `_scan_missing.txt` | 抽样缺失值扫描输出（定位到塔里/圣保罗/卢森格林等边界样本） |
| `_final_render.txt` | 最终渲染核对输出 |
| `_cli_sweep.txt` | **CLI 18 个子命令的完整验收报告**（由 `scripts/cli_sweep.py` 生成，含 stdout/stderr 与退出码） |
| `_cli_sweep_console.txt` | CLI 验收的控制台摘要 |
| `_demo_gen.txt` | 交付示例生成时的命令与输出 |
| `推送失败诊断记录.md` | **GitHub 推送失败的完整排查结论**（含对照实验与逐层证据，并给出用户终端的完成命令） |

## 说明

- 本目录为**运行产物**的归档位置；项目运行/脚本执行产生的日志与报告统一写入这里。
- 文件名以 `_` 开头者为工具运行期的原始日志，保留原名以便与源码中的记录对应。
- 当前记录文件随仓库入库；若后续希望把运行期日志也排除在版本库外，可在 `.gitignore` 增加 `logs/*` 并保留必要白名单。
- 运行时缓存见 `cache/`，测试产物见 `tests/_output/`，交付物见 `output/`。
